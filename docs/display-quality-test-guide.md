# CCP 显示质量改进 - 快速测试指南

## 🎯 改进摘要

我已经完成了 CCP 界面显示质量的全面优化，主要改进包括：

### 1. **字体大小提升**
   - 所有小字号从 11px/12px 提升到 13px/14px
   - 基础正文字号：14px
   - 图表标签：13px 加粗
   - 整体界面放大 10%

### 2. **高 DPI 渲染优化**
   - 启用字体平滑（antialiased）
   - 优化文字渲染质量（optimizeLegibility）
   - Canvas 和 SVG 高清渲染
   - 支持 2K/4K 显示器

### 3. **用户缩放支持**
   - 允许 Ctrl + 鼠标滚轮缩放
   - 支持放大到 300%
   - 适配 Windows 125%/150%/175% 缩放

## 🔧 如果还需要更大

如果你觉得还不够大，可以手动调整：

### 方法 1：修改整体缩放

编辑 `apps/claude-codex-pro-manager/src/styles.css`：

```css
:root {
  zoom: 1.2;  /* 改为 1.2（放大 20%）或 1.3（放大 30%）*/
}
```

### 方法 2：使用应用内缩放（推荐）

启动应用后，按住 **Ctrl** 并滚动 **鼠标滚轮**：
- 向上滚：放大
- 向下滚：缩小

这个缩放会被保存，下次启动仍然生效。

### 方法 3：Windows 系统缩放

如果所有应用都太小，建议调整 Windows 缩放：
1. 右键桌面 → 显示设置
2. 缩放与布局 → 更改文本、应用等项目的大小
3. 选择 125%、150% 或 175%
