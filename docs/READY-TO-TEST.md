## 🔧 如果需要更大

### 方法 1：应用内缩放（推荐）⭐

启动应用后：
- **Ctrl + 鼠标滚轮向上** = 放大
- **Ctrl + 鼠标滚轮向下** = 缩小
- 缩放会自动保存

### 方法 2：修改配置文件

编辑 `apps/claude-codex-pro-manager/src/styles.css`：

```css
:root {
  zoom: 1.2;  /* 从 1.1 改为 1.2（放大 20%）*/
}
```

然后重新构建：
```bash
cd apps/claude-codex-pro-manager
npm run vite:build
cd ../..
cargo build --release
```
