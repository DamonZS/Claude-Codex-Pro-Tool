## 一、中文长文（约 900 字，掘金 / 知乎 / 少数派）

**标题备选**

- 我受够了在四个 AI 编程工具之间手动改配置，于是写了个控制台
- 一个窗口管住 Codex、Claude Code、Claude Desktop：CCP 是怎么做的
- 你的 Token 到底花在哪了？顺手把 AI 编程工具的运维做掉

**正文**

用 AI 写代码的人，桌面上通常不止一个工具：Codex App、Claude Code、Claude Desktop 来回切，中转站换来换去，配置散在 `.codex/config.toml`、`~/.claude/settings.json`、Claude Desktop 的 JSON 里。

真正烦的不是写代码，是这些杂事：

- 这个月 Token 到底花在哪了？哪个模型、哪个项目最贵？只能自己翻日志。
- 想换个中转，得逐个客户端改配置，改一个错一个。
- 上个项目踩过的坑，下个会话又踩一遍 —— 没人帮你沉淀成 Skill。
- Claude Desktop 只能聊天，够不着你的文件系统。

我写了 **CCP（Claude-Codex-Pro-Tool）**，一个 Rust + Tauri 的本地控制台，把这些放进同一个窗口：

1. **用量看板**：本机只读采集，看所有 Agent 的 Token 消耗趋势、缓存命中率、模型与项目排行。
2. **供应商与路由**：Codex / Claude / Claude Desktop 各自记住当前供应商，互不影响；支持直接导入 cc-switch 的配置。三家都会说不同协议（Responses / Chat Completions / Anthropic Messages），格式对不上时由内置的本机代理自动转换 —— 一条本地回环，不经过任何第三方。
3. **蒸馏工作台**：把一个会话或整个项目蒸馏成 Skill、Prompt、用户画像、任务记忆。
4. **Computer Use MCP**：让 Claude Desktop 能截图、点击、输入、拖拽 —— 带急停，默认关闭。
5. **CCP-Bot 本地模式**：想跑 Agent 栈又不想装 Docker / WSL / 虚拟机？它在你选的目录里直接跑 PostgreSQL + 前端 + Bot，装完就能用。
6. **资产清单**：Claude 与 Codex 的插件、Skills、MCP 合成一张清单，点应用只改对应应用。

**几个诚实说明**

- 数据只在本机：不装服务、不上传会话和用量。改配置前会备份，界面里有恢复入口。
- 安装包目前**未签名**，Windows / macOS 会提示来源未知 —— 这是已知项，签名在计划里。
- 协议是 **MIT**：可以随便 fork、二开、商用，保留版权声明就行；名字和官方发布渠道不随 MIT 授权。

Windows 与 macOS 都有安装包，下载在 Releases。项目是刚起步的开源项目，Star 与 issue 都很欢迎。

## 三、English post（Reddit r/ClaudeAI、r/ChatGPTCoding / Hacker News Show HN）

**Title:** CCP – a local control panel for Codex App, Claude Desktop and Claude Code (token dashboard, provider switching with protocol bridging, session→Skill distillation)

**Body**

I run several AI coding tools side by side — Codex App, Claude Code, Claude Desktop — and the annoying part was never the coding, it was the ops:

- Where did this month's tokens actually go? Only answerable by digging through logs.
- Switching a relay means editing `.codex/config.toml`, `~/.claude/settings.json` and Claude Desktop's JSON, one at a time.
- Each client speaks a different wire protocol (Responses / Chat Completions / Anthropic Messages). If your upstream speaks another one, you're stuck.
- Claude Desktop can't touch your files.

So I built **CCP** (Claude-Codex-Pro-Tool): a Rust + Tauri desktop control panel that puts those chores in one window.

What it does:

1. **Token dashboard** for every local agent — read-only collection, usage trends, cache hit rate, model and project rankings.
2. **Provider and routing** — each client remembers its own provider; import from cc-switch works; when the upstream protocol doesn't match what the client speaks, a built-in loopback proxy translates it (Responses ↔ Chat Completions ↔ Anthropic Messages).
3. **Distillation workbench** — turn a session or a whole project into a reusable Skill, prompt, profile or task memory.
4. **Computer Use MCP** for Claude Desktop — screenshot, click, type, drag, with a kill switch, off by default.
5. **CCP-Bot local mode** — run the agent stack without Docker, WSL or a VM: PostgreSQL, the UI and the Bot run as local processes in a folder you pick.
6. **One asset inventory** — Claude and Codex plugins, Skills and MCP servers in a single list; applying only touches the client you pick.

Honest notes: everything stays on your machine (no service, no upload, config files are backed up before edits); the installers are **not signed yet** so Windows/macOS will warn; the licence is **MIT** (fork and commercialize freely, the name and official release channel stay with the project). Windows and macOS builds are in Releases.

It's a young project — feedback, issues and stars all genuinely help.
