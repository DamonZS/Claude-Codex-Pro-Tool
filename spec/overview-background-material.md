# 供应商、客户端与会话页面背景材质统一

## 背景

供应商与路由、客户端与增强、会话页仍有白色或近乎不透明的局部容器，和 CCP 的透明液态玻璃外层不一致。用户要求只修复这些页面的背景表现，不改变页面结构、数据和交互。

## 目标

- 将三个页面的主要容器统一为深色半透明液态玻璃。
- 保留现有布局、内容、控件和状态颜色。
- 保持文字和输入内容可读；数据编辑器和日志等长文本表面继续使用清晰的不透明表面。

## 范围

- 供应商页：环境提示、供应商开关、供应商卡片。
- 客户端与增强页：客户端主容器、客户端列表、详情区、状态栏、能力/运行详情分区。
- 会话页：摘要卡、搜索、时间范围、Agent 筛选按钮、会话列表和会话承载面板。

不修改外层导航、顶部工具栏、窗口尺寸、页面布局、业务数据、路由和交互逻辑。

## 视觉要求

- 使用半透明 `rgba`/`rgb(... / alpha)` 背景和现有 CCP 液态玻璃高光。
- 使用半透明边框、顶部内高光、柔和阴影和 `backdrop-filter` 模糊。
- 深色主题下不使用白色实体卡片；选中和悬停状态保留现有语义颜色。
- 兼容不支持 `backdrop-filter` 的环境，仍保持可读的深色背景。

## 验收

- 类型检查通过。
- Vite 前端构建通过。
- Release 管理器构建通过。
- `git diff --check` 无空白错误。
