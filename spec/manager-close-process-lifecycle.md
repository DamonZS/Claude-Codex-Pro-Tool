# 关闭管理窗口结束 CCP 生命周期

## 背景与目标

关闭 CCP 管理窗口或使用托盘退出时，结束本次安装路径的 CCP 后台 launcher 实例，以及管理器进程内 helper、自动备份等任务。此前统一二进制规格中窗口与 launcher 生命周期独立的约定由本规格覆盖。

## 用户视角与交互

点击窗口关闭按钮或托盘退出即退出 CCP，无隐藏驻留窗口或同路径 CCP 后台进程。关闭不新增确认弹窗。

## 功能与数据要求

- 通过 Tauri 最终退出事件统一清理，再由 Tauri 结束管理器。
- 仅终止完整可执行路径与管理器 `current_exe()` 相同、PID 与管理器不同的实例。未知路径、其他目录同名程序、Codex 与 Claude 客户端保留。
- Windows 路径比较忽略大小写及斜杠差异；macOS 使用完整路径精确比较。
- Windows 终止前重新读取进程路径。终止单个 PID，不递归结束进程树。
- 写入已终止实例数量的诊断记录，不写凭据或用户会话内容。

## 技术约束与范围

沿用 core watcher 的进程枚举与终止工具，保持现有重启/修复逻辑。修改 manager 退出回调、退出专用过滤/清理函数、针对性测试及生命周期文档。不更改开机启动注册、用户配置、插件注入与独立客户端进程。

## 验证与风险

定向测试覆盖同路径实例、当前 PID、异目录同名程序、未知路径及客户端隔离；管理器源码契约覆盖窗口关闭、托盘退出与最终退出回调。Windows Release 现场关闭验收由总体任务统一执行；macOS 实机运行列为未执行项。
