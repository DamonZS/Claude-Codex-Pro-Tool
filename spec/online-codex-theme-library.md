# Codex 在线主题库与删除

## 背景

仓库 `Theme/` 已维护一组经过审计的 Codex 主题 ZIP，但 Manager 目前只能从本地目录或 ZIP 导入。若将全部主题归档编译进多个可执行文件，会明显增加应用和安装包体积。用户需要在主题中心按需从 CCP 官方 GitHub 仓库下载主题，同时避免重复安装，并能删除不再需要的主题。

## 目标

- 在主题中心提供清晰的“下载主题”入口，列出仓库维护的精选主题。
- 只从 `DamonZS/Claude-Codex-Pro-Tool` 官方仓库 `Theme/` 固定路径下载允许的主题 ID。
- 下载后的主题继续经过现有的临时目录校验、原子安装、Mutation Journal 和失败回滚流程。
- 已安装主题在前端不可再次下载，后端在网络请求前再次检查，避免重复下载和并发重复安装。
- 为非默认、非当前主题提供删除操作；删除使用仓库锁和 Journal，失败或中断后可恢复。
- 提供“主题制作指南”入口，说明如何复制现有包、编辑清单、CSS 和图片并通过本地导入验证。

## 非目标

- 不把全部主题 ZIP 编译进 Manager、Launcher 或 MCP 可执行文件。
- 不允许前端提交任意下载 URL，不建立第三方主题市场，也不执行远程脚本。
- 不自动应用刚下载的主题，不删除当前正在使用的主题，不删除 Codex 默认主题。
- 不提供绕过主题校验的在线 CSS 编辑器，也不直接修改主题库中的已安装文件。
- 不修改 Codex 注入、汉化、模型、供应商、凭据或会话行为。

## 用户流程

1. 用户进入“主题中心”，点击“下载主题”。
2. 菜单列出官方精选主题；已安装项显示“已安装”并禁用，未安装项可点击下载。
3. 下载期间页面显示明确进度状态并禁用其他主题写操作。
4. 后端下载固定 ZIP，校验大小、HTTP 状态、主题包结构和主题 ID，然后原子安装。
5. 成功后刷新主题列表；新主题保持未启用，用户点击卡片后才应用。
6. 用户可删除未启用的自定义或下载主题；删除前确认，成功后列表立即刷新。
7. 用户点击“制作指南”时使用系统默认浏览器打开仓库 `Theme/README.md` 的制作说明。

## 功能要求

### 官方目录与下载

- 官方主题采用静态允许列表，至少覆盖仓库当前的 8 个 ZIP：`aurora-glass`、`clockwork-fox-spirit`、`codex-dream-skin-macos`、`codex-dream-skin-windows`、`cyber-changan`、`lotus-fire-nezha`、`obsidian-gold`、`verdant-sanctuary`。
- 下载 URL 只能由后端根据允许列表构造，指向官方 GitHub 仓库中经过审计的固定提交 `Theme/<theme-id>.zip`；前端不得传入 URL。
- HTTP 客户端必须设置连接和总超时、明确的 User-Agent，并在读取流时执行 32 MiB 上限，不能仅依赖 `Content-Length`。
- 每个目录项必须记录预期 ZIP SHA-256；下载内容在解压前必须匹配，仓库分支后续变化不得改变旧版应用实际安装的内容。
- 下载前读取本地主题状态；同 ID 已存在时直接返回“已安装”，不得发起网络请求。
- 下载完成后必须校验 ZIP 内 manifest 的 ID 与请求 ID 完全一致，再进入现有导入事务。
- 网络失败、非成功状态、超限、损坏 ZIP、ID 不匹配或安全校验失败均不得新增主题记录或残留活动 Journal。

### 删除

- 默认主题永久不可删除。
- 当前主题不可直接删除，用户必须先恢复默认或切换到其他主题。
- 删除前必须显示确认；取消不调用后端。
- 删除事务需要暂存主题目录及其历史备份，提交状态后再清理暂存内容。
- 删除中断后，下一次打开主题仓库必须根据 Journal 完成提交清理或恢复主题文件和状态。
- 删除成功不要求重启 Codex，因为只允许删除未启用主题。

### 主题制作

- `Theme/README.md` 必须说明 `theme.json`、`theme.css`、预览图、背景图、许可文件和 ZIP 根目录要求。
- 指南必须强调使用新 ID、只引用本地资源、禁止远程 CSS/脚本，并通过“新建主题”导入验证。
- Manager 只打开官方仓库指南，不直接编辑已安装目录。

## UI 与状态

- “下载主题”使用下载图标加文字，位于主题中心工具栏，不替代现有“新建主题”。
- 下载菜单可滚动，主题名称和状态可读；已安装项同时使用图标和文字表达状态。
- 非默认主题卡片提供垃圾桶图标按钮及 Tooltip/`title`；当前主题的删除按钮禁用并说明先切换主题。
- 下载、导入、应用、删除和背景操作共用互斥操作状态，避免并发写入。
- 删除和下载均显示成功或失败通知；失败保留现有列表。

## 数据与接口

新增 Core API：

```rust
CodexThemeStore::download_official_theme(theme_id: &str)
    -> anyhow::Result<CodexThemeSummary>

CodexThemeStore::delete_theme(theme_id: &str)
    -> anyhow::Result<CodexThemeOperationResult>
```

新增 Tauri 命令：

```text
download_codex_theme(themeId)
delete_codex_theme(themeId)
```

命令沿用现有 `CommandResult` 和主题返回结构，不修改既有 IPC 名称或字段。

## 技术约束

- 复用现有 `CodexThemeStore` 锁、包校验、原子写入、Journal、恢复和隐私边界。
- 不新增前端 UI 库；继续使用现有 React、TypeScript、Lucide 和 Tauri 调用封装。
- 不记录下载响应正文、用户路径或任何凭据。
- 保留用户未提交改动和现有主题包，不生成额外构建目录。

## 交付范围

- Core 下载、重复拦截、预期 ID 校验和事务化删除。
- Manager 命令、动作、操作状态、下载菜单、删除按钮和制作指南入口。
- Core 定向测试、Manager/前端契约检查、规格、验收和主题制作文档。
- 默认 `target/release` 的最新 Release 构建。
