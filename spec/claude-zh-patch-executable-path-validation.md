# Claude 汉化提权可执行文件路径验证

## 背景

Windows 用户执行 Claude 一键汉化时，MSIX 资源目录不可写，需要启动管理器自身的提权子进程。部分机器因系统盘、安装目录或 Windows 扩展路径格式不同，被固定的 `C:\` 路径白名单错误拦截，导致 UAC 尚未执行就返回“可执行文件路径验证失败”。

## 目标

- 使用当前机器实际的 Program Files、Windows 和用户数据目录校验提权可执行文件。
- 兼容大小写差异、非 C 盘路径以及 `\\?\` / `\\.\` Windows 扩展路径前缀。
- 保留目录边界校验，避免把同名前缀的旁系目录视为允许目录。

## 非目标

- 不改变 Claude MSIX 的安装检测、资源写入、UAC 判定或汉化资源内容。
- 不扩大提权范围，不放行任意工作目录中的可执行文件。

## 验收

- UAC 启动前的可执行文件路径校验使用系统实际目录。
- Windows 扩展路径和大小写差异可通过校验。
- `Program Files-Backup` 等仅有字符串前缀相似的目录必须被拒绝。
