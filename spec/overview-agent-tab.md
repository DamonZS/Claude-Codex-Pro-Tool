# 概览双视图与 Agent 概览

## 背景与目标

概览默认展示既有总览；用户通过“总览 / Agent 概览”按钮切换。Agent 概览参照 AI Tracker Agent 页的内容顺序、密度与交互，并融入 CCP 现有液态玻璃材质。

## 范围

- 只改概览页内容及其 Skill 数据采集，不改导航、顶栏、窗口或主题变量。
- 旧的供应商路由、当前请求链路与智能诊断区从概览渲染树中移除，不以样式遮盖；供应商管理页及其操作保持不变。
- Agent 概览依次展示三项统计、横向 Agent 选择、消耗趋势、上下文构成和按模型/项目消耗明细；不展示安全评估。
- Agent 选择和时间范围切换同步更新各项统计；模型/项目切换更新明细。
- 所有数值从 `aitrackerCapabilities.usage.details`、`snapshot.registry` 和 `snapshot.toolCalls` 派生；快照缺席时回退已有请求记录。
- Skill 覆盖按已迁入的 Agent 定义扫描本机 Skill 根目录，按 Agent 去重计数；未安装、采集失败及不支持须有不同状态。工具输出计数和费用无真实来源时显示“未采集”，不填预览值。
- Skill 根目录相对于真实用户主目录解析；Agent 安装状态按定义中的本机检测位置判定，不依赖是否已产生用量事件。已安装 Agent 显示绿色状态点并排在未检测到的 Agent 前面，组内仍按 Token 排序。

## UI 与数据

- 顶部双按钮为分段控件，初始选中总览。
- Agent 轨道可水平滚动，保留左右按钮、选中强调线、状态点、Token 和会话数。
- 趋势使用每日 Token 柱形和折线、纵轴/横轴以及今日、近 7 天、近 30 天、全部和自定义日期范围；空数据有说明。
- 上下文构成显示缓存命中率、真实 Token 分项、工具调用数和说明；缺失项目明确显示未采集。
- 明细显示模型/项目、相对用量条、Token、事件或会话数和费用状态。
- Skill 采集沿用定义中的根目录、环境变量覆盖、标记文件和最大深度；跳过隐藏目录及符号链接，不读取 Skill 正文。覆盖数不随用量时间范围变化。
- 图表和面板沿用 CCP 玻璃边框、透明度、模糊、文字变量，不引入 AI Tracker 的白色主题。
- Agent 概览内容区支持纵向滚动，可访问上下文构成和底部消耗明细；卡片与 Agent 轨道采用总览同级的透明玻璃背景、高光、模糊和阴影，不修改外层主题。

## 验证

前端类型检查、数据层定向测试、概览契约测试、Vite 构建和默认路径的 Tauri Release 构建；检查真实主目录扫描、已安装排序、滚动容器与玻璃材质。不以浏览器预览作为验收。
