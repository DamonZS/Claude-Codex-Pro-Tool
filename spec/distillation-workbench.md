# 蒸馏工作台

## 背景
将“客户端与增强”页面升级为基于 AITRACKER 蒸馏工作台的完整本地工作流，同时保留 CCP 液态玻璃视觉和现有供应商配置。

## 目标
- 将左侧“客户端与增强”入口、页面标题和页面主体统一替换为“蒸馏工作台”；页面内不得残留旧客户端状态面板。
- 按 AITRACKER 交互结构呈现统计卡片、配置/历史切换、快速/高级配置、会话/项目选择、输出资产分组和任务操作，并使用 CCP 液态玻璃主题。
- 前端采用 AITRACKER 蒸馏工作台的页面结构与交互语义后在 CCP 组件体系中直接落地；不把 AITRACKER 整个源码树复制进仓库。
- 提供会话/项目材料选择、今日/7天/30天/全部过滤、会话预览及消息片段选择；保留来源 Agent 与项目归属。
- 提供快速/高级配置、供应商与模型选择、输出类型、任务阶段/进度/取消、历史和候选审批。
- 迁移并实际采用 AITRACKER 蒸馏领域逻辑：材料范围校验、隐私清理、边界保留压缩、分类型提示词、输出结构质量检查/修订、离线/模型/fallback/budget 状态和持久化任务状态；运行时只保留 CCP 内部必要实现。
- 输出 Skill、Workflow、Prompt、Profile/Persona、Task Memory，并按类型写入 CCP 本地目标库；审批前不写入目标库。
- 供应商和模型只能来自 CCP 已配置的供应商数据。

## 非目标
- 不重新设计供应商配置格式。
- 不改变无关页面与既有候选审批接口的语义。

## 用户视角
用户进入“客户端与增强”，选择材料、供应商、模型和输出类型，启动蒸馏，观察进度，查看结果并保存/审批或取消候选。

## 功能要求
1. 导航与页面：导航和面包屑显示“蒸馏工作台”；该路由不渲染通用页面标题/副标题栏，也不额外重复工作台大标题，内容从统计卡片开始；旧“客户端与增强”页头、客户端状态横幅及状态矩阵不再出现在该路由。
2. 材料：按会话/项目、今日/7天/30天/全部筛选；快速模式不添加 AITRACKER 中不存在的素材搜索；项目模式按项目汇总为单行并整组选择，支持预览、全选/取消和连续消息片段范围；请求只携带被选择的会话引用和片段边界。
3. 配置：快速模式与高级模式；展示能力资产/记忆资产；供应商下拉仅显示 CCP 已配置供应商，模型随当前供应商联动且不出现独立硬编码模型列表。
4. 执行：启动返回可查询任务 ID；进度来自后端阶段而非前端计时器；取消更新持久化任务状态；重复提交、无材料、供应商错误和任务错误均给出可见状态。
5. 领域：对私密路径、API key、token、password 等脱敏；仅处理选择的会话/片段；按输出类型生成规范结构并清理标题与长度；保留 model/offline/fallback/budget-exceeded 状态和质量检查反馈。
6. 持久化：任务状态、结果和候选历史可查询；重启后可查询终态任务；候选可审批/取消；审批前不写入目标库。
7. 输出：Skill/Workflow/Prompt/Profile/Persona/Task Memory 按类型写入对应 CCP 本地库；保存成功更新候选状态，失败保留候选与输出。
8. 视觉：页面不再套用“客户端与增强”旧内容；不显示 AppShell 通用页标题横幅或重复的大标题；统计卡片紧接全局工具栏，信息顺序为统计卡、配置/历史切换、配置卡头与模式/模型、紧凑素材筛选条与列表、双资产卡、卡片内执行行；桌面配置卡头将供应商、模型和管理模型控件与模式切换保持同排，窄屏才堆叠；高级模式使用独立提示词标签和完整文本框，置于材料筛选之前，不添加参考界面没有的预设胶囊或离线模型行；Agent/项目筛选不得另占整行挤压素材列表；产出类型保持可点击选择但呈文本选项，不使用胶囊底色，记忆类型显示 Profile / Persona 与 Task Memory；Token 数量达到百万/十亿时分别使用 M/B 紧凑单位；卡片透明度、边框、字体、间距、响应式列数与 CCP 现有液态玻璃主题一致，并参照 AITRACKER 工作台的紧凑层级与彩色统计数值。
9. 模型调用：选择材料后任务进入可观察的模型请求阶段；使用配置供应商的协议、Endpoint、模型与认证发送请求；无法解析模型文本时按失败处理并显示任务原因，不得静默将空响应当作模型成功或离线回退。

## 数据与接口
- 前端通过现有 Tauri call 入口调用命令。
- 后端提供材料查询、供应商/模型列表、创建/查询/取消蒸馏任务、候选历史、审批/取消、输出保存命令。
- 所有持久化使用 CCP 本地应用数据目录，敏感值不得写入日志。
- 供应商、模型凭据和真实 model profile 仅在 Rust 后端加载；前端传供应商 ID/模型 ID，不传密钥。

## 技术约束
- React/Vite/Tauri/Rust 现有架构。
- 优先复用现有 DistillationCandidate、供应商路由与设置存储。
- 只做最小必要改动，不引入重复模型配置。

## 交付范围
规格、验收标准、React 工作台、Tauri/Rust 领域与命令、持久化、测试、构建验证。
