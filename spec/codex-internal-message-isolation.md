# Codex 内部通讯隔离

## 背景

Codex 桌面端偶发把 agent-to-agent 的传输帧和协议错误渲染成普通会话消息，用户会看到“由 ChatGPT 从另一项任务发送”及 `function_call_output` 错误。

## 目标

在 CCP 注入层隔离已知内部传输消息，避免它们继续出现在用户会话视图中；不修改后端线程数据，不隐藏普通用户或助手消息。

## 功能要求

- 识别内部转发标记和已确认的 Responses WebSocket 协议错误。
- 隐藏命中的最小会话 DOM 节点，并写入可诊断属性。
- 页面首次注入和后续 DOM 变更均执行隔离。
- 普通消息、持久化数据和 Codex 原生传输不被改写。

## 非目标

无法从 CCP 修复 Codex 桌面端传输层本身；若桌面端改变文案或结构，需要更新标记适配。
