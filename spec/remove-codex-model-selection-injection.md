# 移除 Codex 模型选择注入

## 背景

Codex 当前已经能够正常显示可用模型。CCP 过去为模型白名单和自定义模型增加了前端注入，可能在原生模型菜单中重复追加 `gpt-5.6-*` 等模型，并改写 Codex 的模型状态或请求参数。

## 目标

- 完全停止 CCP 对 Codex 原生模型选择器的注入、追加、改写和请求覆盖。
- 删除“模型白名单解锁”配置入口及其前端状态补丁。
- 保留与模型选择无关的 Codex 功能；服务层级控制若需要读取当前模型，只能读取状态，不能修改模型列表或选择结果。

## 非目标

- 不修改 Codex 官方模型菜单、模型目录或账号数据。
- 不修改供应商配置、Base URL、API Key 或代理路由。
- 不删除服务层级控制本身，但不得借此重新启用模型选择注入。

## 功能要求

- 注入脚本不得安装模型 JSON/Statsig/React/App Server 状态补丁。
- 注入脚本不得修改 `model/list`、`list-models-for-host` 或请求中的 `model` / `model_slug` / `modelId`。
- 注入脚本不得扫描模型菜单、创建 `CCP 模型增强` 项或保留模型菜单观察器。
- 管理工具不得显示或保存“模型白名单解锁”开关。
- 旧配置中的 `codexAppModelWhitelistUnlock` 应被忽略，不得再次驱动注入。
- Codex 重启后菜单只由 Codex 原生逻辑渲染，页面中不出现 CCP 模型增强组。

## 交付范围

- `assets/inject/renderer-inject.js` 模型选择注入链。
- 管理工具设置类型、默认值、设置页和能力摘要。
- Core 设置反序列化及相关契约测试。
- 对应验收文档。
