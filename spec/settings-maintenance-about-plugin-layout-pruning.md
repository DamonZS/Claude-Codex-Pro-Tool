# 设置、维护与插件页精简

## 背景和目标

当前管理器设置页仍展示已停用的增强开关、设置文件位置、Claude 一键汉化和 CLI 包装器；维护页仍展示不再需要的检查修复、入口管理和自动接管区；插件页顶部说明占用空间，仓库状态卡需要放到工具列表之后。将这些无效入口移除，并把关于与更新信息收进设置页，保持页面功能边界清晰。

## 功能要求

- 设置页不再渲染设置文件位置、Codex 增强矩阵、Claude 一键汉化和 CLI 命令包装器。
- 设置页移除偏好设置摘要面板及其刷新/保存按钮；保留关于 CCP、版本、Release 更新、联系信息和运行日志。
- 设置、维护与插件/Skills/MCP 页面不显示全局页面标题带及其副标题；其他页面标题保持原样。
- 独立关于路由与侧栏入口移除；历史导航到 `about` 时回退到设置页。
- 维护页移除检查与修复、入口管理、自动接管三个面板及其前端动作入口；保留未被用户删除要求覆盖的应用路径与 Claude 状态信息。
- 插件页移除“统一管理插件、Skills、MCP、来源、风险与依赖”说明副标题；Codex 插件仓库和 Claude 插件仓库状态卡出现在插件/Skill/MCP 内容之后。
- 删除 CLI 包装器和 Claude 一键汉化的前端设置读写、刷新与动作调用；保留配置反序列化兼容字段，避免旧用户配置加载失败。

## 技术约束

- 沿用现有路由、Panel、液态玻璃样式和 Tauri 命令调用方式，不新增依赖。
- 删除仅由这些入口使用的前端代码与测试断言；共享后端能力仅在确认无其他调用方后删除。
- 不修改用户配置文件和 Claude/Codex 官方安装文件。

## 交付范围

前端路由、设置/维护/插件页面、前端动作桥接、相关类型与源码契约测试，以及本规格对应的验收文档。
