# 我的任务多视图模式

## 背景

上游 Multica 的 `MyIssuesPage` 通过 `IssueSurface` 提供 board、list、table、swimlane 四种任务视图。本地“我的任务”目前只有 board，无法按列表、字段表格或分泳道方式扫描任务。

## 目标

- 在“我的任务”中提供 board、list、table、swimlane 四种模式。
- 四种模式都使用同一份已查询、已筛选的 Issue 数据，不复制或伪造任务状态。
- 模式切换只影响当前界面呈现，不改变任务数据。
- 首屏结构与上游 `MyIssuesPage -> IssueSurface -> BoardView` 对齐：只显示页面标题、筛选/视图工具栏和横向状态看板，不插入本机工具调用或 Skill 事件平铺列表。
- 看板采用上游深色工作区视觉比例：七列横向滚动、紧凑列头、卡片化任务和状态色区分。

## 非目标

- 不新增服务端执行器、daemon 或 Codex runtime。
- 不把只读原生快照变成可编辑任务。

## 功能要求

- 标题栏使用任务图标和“我的任务”标题；不显示工作区模块菜单、任务数量或与原版无关的入口。
- 工具栏保持单行的左右分组：左侧为 Scope 与图层 ViewBar，右侧为工作中智能体、筛选、显示、当前视图和刷新。窄窗口可横向滚动，不得把控件折行堆叠。
- board/list/table/swimlane 四个互斥模式收纳在当前视图菜单内，并标记当前模式；新增视图与管理视图通过左侧图层菜单进入页面内弹层。
- board 保留现有拖放状态列行为。
- list 按任务逐行展示标题、状态、优先级、负责人和项目。
- table 以稳定列展示上述字段及更新时间。
- swimlane 按状态分组，每组展示任务列表。
- 无任务时显示明确空态；模式切换不触发额外写入。
- `my-issues` 首屏不得渲染 `当前活动`、`来源：Codex 本机活动投影` 或工具/Skill 事件列表；原生活动数据只能在其专用页面展示。
- Codex 执行 Host 不可用时，不在看板标题或工具栏插入长提示；执行操作保留不可用状态和明确的悬停说明。
- “已分配”无任务时，在看板内容区显示空态和“查看全部任务”操作，不在标题栏与看板之间插入提示。
- 图层菜单提供“新增视图”和“管理视图”；新增视图可保存当前范围、模式和紧凑显示设置，管理视图可应用和删除本机视图。
- 筛选、显示和当前视图均为独立可操作入口，改变后立即更新任务呈现。
- 点击任一看板列头的“+”必须打开任务创建遮罩层，不跳转到会话或通用表单。创建层以约 600px 宽、340px 高的居中任务编辑面板呈现；遮罩只降低看板可见度，外层背景继续使用 Codex 当前主题。
- 创建层包含来源路径、关闭与可用的展开按钮、任务标题、描述、状态、优先级、智能体分配、标签、项目和更多字段入口；列头“+”传入的状态必须预填到状态控件。
- 创建层支持取消、点击遮罩关闭、Esc 关闭、Ctrl/Cmd+Enter 提交，以及“继续创建”。继续创建成功后保留面板并清空标题和描述，同时继承用户本次选择的状态、优先级、项目、执行者与标签。
- 本地任务协议未提供附件上传时，附件入口必须明确不可用原因，不得伪造文件已上传或已关联。

## 交付范围

- `assets/inject/renderer-inject.js` 模式状态、工具栏、任务创建层和三种渲染器。
- 对应验收文档和语法/前端构建验证。
