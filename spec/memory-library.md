# 记忆库页面与记忆编辑弹窗

## 背景

蒸馏工作台把会话蒸馏成「画像」和「任务记忆」后，产物写到本机记忆目录并在历史卡片上提供
「去记忆库查看」。当前点击它只会打开系统文件夹（`open_distillation_library`），没有可浏览、
搜索、编辑、导出或删除记忆的界面；用户只能去资源管理器里翻 Markdown 文件。

参考 AITracker 的记忆库页面（统计卡 + 搜索 + 分类筛选 + 记忆卡片 + 编辑弹窗）补齐 CCP 自己的
**记忆库**一级页面，视觉使用 CCP 液态玻璃风格。

## 目标

- 新增一级导航「记忆库」，展示本机由蒸馏产出的画像 / 任务记忆。
- 支持搜索（标题、正文、来源）、按类型筛选（全部 / 画像 / 任务记忆）、重置筛选。
- 支持单条记忆的编辑、导出 Markdown、删除。
- 蒸馏工作台历史卡片的「去记忆库查看」跳转到该页面，不再打开资源管理器。

## 非目标

- 不做知识库数据库、向量检索、Jarvis 洞察卡、首次引导。
- 本期页面不提供「新增记忆」入口（编辑弹窗已支持新增形态，后续可接）。
- 不改变蒸馏流水线、候选自动批准与记忆文件写入规则。

## 用户视角

1. 在蒸馏工作台跑完「画像 / 任务记忆」，或点击历史卡片的「去记忆库查看」。
2. 进入「记忆库」：顶部看到记忆总数 / 画像 / 蒸馏沉淀 / 最近更新，下面是搜索与分类。
3. 每条记忆卡片显示类型、标题、正文摘要、更新时间，以及「导出 MD / 编辑 / 删除」。
4. 点击「编辑」打开「编辑记忆」弹窗：可改类型、一句话标题、说明，然后保存；「导出 MD」把
   frontmatter + 完整正文写到系统下载目录。
5. 删除后卡片立即消失，列表计数同步更新。

## 功能要求

1. 统计卡（4 列，窄屏 2 列）：
   - 记忆总数 = 条目数，副文案「画像 N 条 · 任务记忆 N 条」
   - 画像 = 画像条数，副文案「关于你这个人：偏好与习惯」
   - 蒸馏沉淀 = 来源为蒸馏的条数，副文案「手动录入 N 条」（本期恒为 0）
   - 最近更新 = 最新 `updatedAt`，格式 `MM/DD HH:mm`，副文案「导出后即可直接放进上下文」
2. 搜索行：搜索框 placeholder「搜索记忆标题、正文或来源」；右侧筛选标签「全部 N / 画像 N /
   任务记忆 N」与「重置」；搜索与筛选在页面内即时生效。
3. 列表头：左侧「共 N 条记忆」（为当前筛选后的数量），右侧提示「导出成 .md 后，直接丢进任意
   AI 助手的上下文即可」。
4. 记忆卡片：类型图标 + 类型名、标题单行省略、正文最多 4 行摘要、更新时间、三个操作按钮
   （导出 MD / 编辑 / 删除）。
5. 空态：标题「还没有记忆条目」，副文案「在蒸馏工作台选择「画像」或「任务记忆」，产物会自动
   沉淀到这里。」；搜索无结果时显示「没有匹配的记忆」。
6. 编辑弹窗：
   - 标题「编辑记忆」（新增形态为「新增记忆」）
   - 「是什么」：两个可选项「画像（关于你这个人：偏好、习惯、口味）」「任务记忆（关于约定与
     决策：我们定了什么规矩）」
   - 「一句话标题」单行输入（≤256 字符）
   - 「说明」多行输入（≤24000 字符，支持 Markdown）
   - 底部「取消 / 导出 MD（仅编辑已有条目）/ 保存」；标题或正文为空时保存禁用
   - Esc 或点击遮罩关闭，保存中不可关闭
7. 删除命令一次最多 100 条，与蒸馏候选删除上限一致。

## 数据与接口

存储沿用蒸馏候选与记忆文件，不新增数据库：

- 候选：`~/.claude-codex-pro/aitracker/distillation.json`（画像 `kind=persona`、任务记忆
  `kind=memory`）。
- 记忆文件：`~/.claude-codex-pro/aitracker/distilled/profiles/<candidate-id>.md`、
  `.../task-memory/<candidate-id>.md`。

Tauri 命令（均为 `spawn_blocking`，返回 `MemoryLibraryPayload`，导出返回路径）：

| 命令 | 入参 | 行为 |
| --- | --- | --- |
| `load_memory_library` | 无 | 读取全部已批准画像 / 任务记忆，按 `updatedAt` 倒序 |
| `save_memory_library_entry` | `{ id?, kind, title, body }` | 校验类型与必填；更新候选并重写记忆文件；`id` 为空时新建 |
| `delete_memory_library_entries` | `{ ids }` | 删除 1–100 条候选与对应记忆文件 |
| `export_memory_library_entry` | `{ id }` | 写 `title/type/source/updatedAt` frontmatter + 正文到下载目录，返回路径 |

`MemoryLibraryPayload`：`{ entries: [{ id, kind, title, body, source, createdAt, updatedAt }],
counts: { total, persona, memory }, updatedAt }`。

## 技术约束

- React + Tauri，前端新增 `src/components/memory/` 目录内的页面、弹窗、样式与类型。
- 复用现有 `CommandResult`、`ok`/`failed`、候选与记忆文件读写，不引入新依赖。
- 页面样式只使用 CCP 现有 CSS 变量（`--workspace-*`、`--ops-*`、`--finish-*`），不硬编码品牌色。
- 不修改蒸馏流水线行为；「去记忆库查看」由打开文件夹改为页面内跳转。

规格、验收、Rust 命令与单测、React 页面与编辑弹窗、样式、路由与导航接线、构建验证。
