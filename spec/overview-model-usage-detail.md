# 概览页数据看板截图还原

## 背景

用户要求推翻上一版概览页内容，严格按 2026-09-27 提供的截图重做，同时明确限定只改概览页内部，不动 CCP 外层导航、顶栏、页面框架和既有液态玻璃材质。

## 目标

- 在“总览 / Agent 概览”视图切换同一行放置 24 小时/7 天/30 天范围；移除单独的数据标题与采集状态行。总览依次呈现摘要、运营指标、Agent 筛选、Token 消耗趋势、模型消耗、项目消耗总览和近 12 个月活跃日历。移除此前额外插入的 Agent 使用排行、Provider 请求占比、按小时 Agent 活跃度和 Token 燃烧榜，不在总览重复趋势或模型明细。
- AITRACKER 首页中的“安全态势”“安全扫描”“简报生成”三张卡片及其操作内容不进入 CCP 总览。
- 一比一还原参考图中的标签、排行信息、模型名称、数值、统计周期和紧凑排布；数值必须来自本地采集结果。
- 有本地请求记录时，统计卡片和图表使用真实记录；没有记录时只显示明确空态，不显示截图预览或固定演示值。
- 保留请求时间范围筛选、模型/项目分组状态、空数据、加载及读取错误状态。

## 非目标

- 不改左侧导航、顶部工具栏、AppShell、页面外层布局、全局样式/主题变量或液态玻璃透明材质。
- 不新增远端请求或把截图预览值作为采集数据/真实账单；本任务允许为本地记录补齐 session/project 元数据。

## 内容与布局

1. 顶部同一行左侧为“总览 / Agent 概览”，右侧为 24 小时、7 天、30 天范围；范围控件只在总览生效并展示，不出现单独的数据标题行。
2. 顶部摘要卡顺序为 Agent 覆盖、蒸馏资产、今日消费；运营指标卡顺序为 Token 消耗、费用估算、会话总数、缓存命中率、Agent 活跃、蒸馏产出。卡内包含语义图标、核心值、统计周期和真实数据辅助文案；费用无价格来源时显示“未计价”。
3. Token 趋势独占一行，堆叠展示缓存读取、输入、输出及上一周期虚线；悬浮时显示真实时间和 Token 值，浮层文字不得因 SVG 拉伸变形。
4. 模型消耗逐行展示模型名、调用次数、Token、费用、占比、环比和横向用量条。项目消耗总览展示圆环、项目总数、总 Token、TOP 3/5/10、项目名、占比、Token、会话和环比。
   模型明细默认平铺全部已采集模型；项目表、日历与趋势悬浮层继续沿用概览的透明液态玻璃材质，不使用不透明黑色覆盖层。
5. 活跃日历展示近 12 个月的月份标签、星期标记、按 Token 着色的日期格、活跃天数、最长连续天数、累计 Token 和深浅图例。
6. 总览内容允许纵向滚动；宽屏保持 6 列指标，窄屏折行，文字与数值不得溢出。外层页面和玻璃材质不变。

## 数据规则

- Agent 范围和时间范围先过滤，再计算请求数、Token、成功率和平均耗时。
- Provider 占比与 Agent/模型排行由 `RequestRecord` 聚合；模型 Token 优先用 `total_tokens`，缺失时合计已有 Token 字段。
- 采集器参考 aitracker：Codex 从 `session_meta.payload.id`/`cwd` 和 `event_msg.token_count` 读取；Claude 从 `sessionId`/`cwd`、assistant `message.id`/`usage` 读取；同一 session/message 的重复快照按最大累计值去重。
- `session_id` 用于活跃会话去重，`project` 只保留工作目录末段用于按项目明细；不得把完整本地路径暴露到 DTO。
- Provider、模型、Token、请求时间范围、Agent/Provider/项目聚合均来自本地扫描或 CCP 代理请求日志。缺失字段保持“未采集”，不得用默认值填充。
- 概览数据看板优先使用 `RequestTimelineResult.usage_snapshot.details` 的统一 AITRACKER 事件；仅当快照字段缺失时回退 `records`，保证旧版本命令结果仍可展示。
- 当前本地请求记录没有可验证的价格字段，因此费用显示“未计价”；不得显示 0、固定金额或把 Token 数冒充费用。没有记录时只显示明确空态。

- 项目明细采用源组件的 HTML 表格结构、颜色标记、TOP 3/5/10 分段及其他项目行；比较周期文案为“比较周期 · 较前 7 天”（随周期切换）。
- 总览只保留一个页面纵向滚动容器，鼠标滚轮可到达日历底部；不改外层框架和玻璃材质。

- 统一原生采集包含归档会话，Codex 净输入扣除缓存，避免趋势与命中率重复计算；快照完整性与有界扫描诊断必须真实。

- 页面修改范围限定于 `OverviewDataDashboard`、其概览内部面板及 `request-timeline.css` 局部规则；为提供真实字段允许同步修改 `RequestRecord` 与 `request_history` 本地只读 scanner，不改变外层 UI。
- 保留液态玻璃背景、边框、光泽、投影与模糊现有声明。
- 更新对应验收文档和概览 UI 契约测试；运行 manager TypeScript 检查、Vite 构建、Windows 概览契约测试及默认 `target/release` 的真实应用构建。不使用浏览器预览验收。
# 2026-09-29 采集刷新约束

- 用量与能力读取各自防重入；10 秒定时刷新只更新用量快照，避免同时重复全量扫描。
- 概览切入时能力数据只采集一次；首屏后只刷新请求快照，避免重复能力扫描抬高内存峰值。
- 总览与 Agent 概览优先消费最新请求快照；能力数据保留切页与显式刷新更新路径。

## 2026-09-29 趋势与指标核对

- 7 天趋势柱宽收窄，日期标签加大、加粗并靠近柱底；24 小时和 30 天的首尾柱仍完整可见，悬浮命中范围不缩小。
- 趋势区按参考图排列：绿色缓存读取在底、蓝色输入居中、紫色输出在顶；标题下有对应周期的平均 Token、环比和峰值日期/Token，右侧显示同一筛选范围的缓存命中率。悬浮显示日期、总 Token、各 Token 组成和去重会话数。
- 概览 Token 数达到十亿时使用 `B` 单位，不再显示四位数 `M`；不足十亿时沿用现有 `M/K` 规则。
- 缓存命中率按选定 Agent 与时间范围内的 `缓存读取 / (净输入 + 缓存写入 + 缓存读取)` 计算，和 AITracker 的观察口径一致。核对实际采集的分子、分母、各 Agent 构成与截断诊断，不通过调整公式掩盖数据差异。
- 项目消耗表格继承概览液态玻璃透明背景，并在可用宽度内展示全部列，不触发桌面端横向滚动；不修改全局表格规则。
- 趋势日期位于各自柱子中心的下方，日期轴和图例之间保留独立间距，不让图例遮住首日标签。
