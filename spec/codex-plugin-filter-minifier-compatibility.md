# Codex 插件过滤的压缩名称兼容

## 背景与目标

Codex 26.930.4958 将构建渠道插件过滤中的函数名改为 `Mj`，现有 `u/ne` 字符串识别遗漏，插件页只剩少量条目。修复现有解锁开关下的渠道过滤，保留搜索、分类及安装接口行为。

## 用户视角与交互

开启插件解锁后，公开插件页仍显示已有市场插件；输入搜索词继续筛选结果。关闭开关或处于现有禁用模式时保留原生过滤。页面布局、提示、加载和空态沿用现有实现。

## 功能与数据要求

- 仅识别完整单参数箭头表达式 `!CHECK(plugin.marketplaceName)||plugin.marketplaceName===flavor`；通过反向引用确认两处参数一致，匹配不依赖压缩符号名。
- 保留官方市场样本和实际被过滤样本的条件，普通搜索或带额外条件的回调照常执行。
- 补丁版本由 13 提升至 14，使已运行窗口重新安装过滤补丁。
- 不修改已兼容的 `plugin/list` 请求名、插件安装参数、配置存储或官方程序文件。

## 技术约束与交付

修改 `assets/inject/renderer-inject.js`、现有 Rust 注入契约，新增执行生产函数的 Node VM 行为测试；无新增依赖。保存原字节、补丁、真实验证记录及可执行还原脚本。构建默认 Release 并重新注入后检查实时版本、过滤与搜索结果。主要风险为全局 Array.filter 补丁误识别，必须用负向行为用例限定范围。
