# Codex 路由就绪与删除确认修复

## 背景与目标
用户开启国模路由后请求未发出；现场备份指向 57321，但该端口启动绑定失败，启动器 helper 使用 55180。供应商切换仍返回成功。另有删除确认后会话保留的报告，需验证确认事件和桥接状态。

## 用户流程与功能要求
- 使用或开启 Codex 路由时，先确保配置要求的本地代理已启动，再写入配置；失败时返回明确错误并保留原活动供应商。
- 关闭路由及官方登录不依赖代理启动；Claude 系列沿用现有流程。
- 删除一次点击只确认一次；取消不提交，确认仅提交一次，成功后移除行，失败保留行并显示原因。
- 桥接无响应时给出结果待核实提示，避免永久等待和自动重试删除。

## 接口与技术约束
沿用现有 helper、供应商命令与 /delete 桥接协议。保留模型目录修复。测试仅用隔离页面、临时数据库与本地模拟服务。保持现有运行进程及用户配置。
