# 项目消耗总览圆环对齐

## 背景与目标

概览页的项目消耗图目前是实心扇形，与 AITracker 的细线圆环不一致。本次只调整该图的绘制，不改变 CCP 外层布局、透明液态玻璃材质、项目采集或其他卡片。

## 用户视角与功能要求

- 项目消耗总览显示灰色底环、按当前 TOP 3/5/10 项目 Token 占比分段的彩色圆环、分段间细小留白，以及中心的项目总数和“项目”标签。
- 彩色分段与右侧 TOP 列表使用相同的项目顺序及颜色；未进入 TOP 的项目保留在灰色底环中。
- 切换 TOP 按钮时圆环和占比文字同步更新；无项目数据时仅显示底环和 0 项目。

## UI、数据与技术约束

- 参照 AITracker `DashboardProjectOverview` 的 `ThinRing`：SVG 100×100、半径 42、线宽 10、起点旋转 -90 度、各段间隔约 1.4 单位。
- 沿用现有 `projectUsage` 的真实聚合 Token、项目数和 `share`，不另造数据、不变更数据接口和错误处理。
- 只修改概览页项目圆环组件及局部 CSS；不改外层导航、主题变量、其他卡片和采集逻辑。

## 交付与验证

交付圆环实现及局部样式；验证 TOP 切换、空态、前端类型检查、Vite 构建和默认路径的 Release 构建。
