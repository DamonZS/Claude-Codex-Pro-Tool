# 概览 Agent 品牌图标与顶栏对齐

## 背景与目标

用户反馈总览 Agent 筛选文字过小、缺少图标，Agent 概览把 icon 类型字符串显示为图标，并要求顶栏操作组靠右。

## 范围与用户行为

- 总览筛选文字由 10px 增至 13px，每个 Agent 名称前显示本地品牌图标；“全部 Agent”保留文字。
- Agent 概览按 Agent id 使用正确品牌资源，不显示 claude/other 等类型字符串；未知品牌回退名称首字母。
- 品牌资源来自用户指定的 AI Tracker brand-logos 目录，复制到现有前端资源目录，运行时不依赖 H 盘或网络。
- 顶栏 Agent、搜索、供应商保持左侧；更新、启动/重启、汉化操作组贴右侧内容边界。

## UI、数据与技术约束

- 使用一个精简共享品牌组件和必要 id 别名，保留品牌原始颜色，单色图标适配深浅背景。
- 保留筛选、选择、统计聚合、滚动、按钮处理与玻璃样式；小窗口保持可用。
- 只调整相关 JSX、CSS、资源和测试；不改后端、用户数据、依赖、已有未提交改动。
- 本次补充允许调整顶栏布局；原 overview-agent-tab 规格其余行为保持不变。

## 交付与验证

前端类型检查、Vite 构建、默认 Release 构建；实机验证两视图图标加载、13px 字号、选择行为，以及 1180/960 内容宽度顶栏几何。保存修改前、修改后、独立副本回滚的同输入行为和原始哈希。
