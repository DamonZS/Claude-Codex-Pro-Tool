# CI 渲染器契约测试同步

## 背景

渲染器注入脚本的行为契约测试通过源码片段断言关键请求和提示文案。功能演进后，旧断言仍要求已移除的本地“不支持执行”记录逻辑，或要求已替换的修订号条件，导致 Windows `cargo test --workspace` 失败并阻断自动打包。

## 目标

- 让 `cdp_bridge` 契约测试反映当前真实实现。
- 自动化手动触发必须断言控制面 `/multica/autopilots/trigger` 请求及成功提示。
- 编辑保存必须断言统一传递 `expectedRevision`。

## 非目标

- 不改变自动化运行时、Codex Host 能力检测或工作区数据模型。
- 不删除任何现有功能测试。

## 验收

在 Windows 和本地环境执行 CI 选定的 core 回归集合时，相关 `cdp_bridge` 测试不再因旧字符串契约失败；完整工作区测试继续作为本地开发验证，不作为每次打包的阻断步骤。
