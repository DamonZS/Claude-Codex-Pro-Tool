# 系统提示词组合预览与部署

## 背景

内容库包含来自多个研究来源的提示词。当前页面一次只能给每个客户端选择一个条目，用户无法在写入前检查多个来源的顺序、重复和体积，也容易把相互冲突的指令直接拼接。

## 目标

- 允许用户为一个客户端按顺序选择多个内容库条目。
- 组合结果在写入前可预览，并显示去重项、警告和摘要哈希。
- 组合内容使用确定性格式，保留每个来源的标题和顺序；不自动执行来源中的脚本或工具。
- 组合结果复用现有备份、受管投放、重复投放和还原流程。

## 非目标

- 不自动判断哪一份提示词“最强”，不隐式改写用户正文。
- 不执行组合内容，不修改供应商请求或客户端安全策略。
- 不改变现有单来源投放接口的兼容行为。

## 功能要求

- 组合请求至少包含一个来源，最多 8 个来源；单个来源最多 256 KiB，组合正文最多 1 MiB。
- 来源按请求顺序输出；完全相同正文只保留第一次，并返回去重警告。
- 输出包含固定标题、来源标题、来源正文和组合摘要 SHA-256；来源标题必须转义为普通文本。
- 空正文、超限、重复 ID 或请求超过来源数量上限时拒绝组合，不产生部署状态。
- 组合预览失败不得修改客户端文件；用户确认后才调用既有投放命令。

## 验收标准

- 相同输入得到字节级相同输出和摘要哈希。
- 顺序变化会改变输出；重复正文被去重并产生警告。
- 空输入、超限输入和重复来源 ID 均返回明确错误。
- 页面能选择多个条目、查看预览摘要并将预览内容作为普通投放正文。
- 既有单来源投放、备份、回滚和还原测试保持通过。
