# Agents 模块原生智能体投影

## 背景

上游 Multica 的 Agents 页面需要显示真实智能体及其活动。CCP 已从 Codex 状态库读取父子线程关系，但原生子智能体此前只在“我的任务”附加区域展示，Agents 路由在本地 Agent 定义为空时会误显示空态。

## 目标

- `agents` 路由在本地 Agent 集合为空时展示 `codex_native_agents` 只读投影。
- 展示原生线程 ID、父线程、项目路径和更新时间等有界元数据。
- 原生投影不得出现编辑、删除、启停、标签或其他 Multica 写操作。

## 约束

- 只读取本机 Codex SQLite 投影，不创建或修改 Codex thread。
- 不把原生子智能体推断为可再次派发的 Agent 定义。
- 本地 Agent 集合非空时优先展示本地集合，不混入原生快照。

## 交付

- 更新注入层 Agents 路由的只读 fallback 和渲染分支。
- 增加静态回归验收，确认原生条目没有写操作入口。
