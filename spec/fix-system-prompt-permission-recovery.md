# 修复 Windows 安装后系统提示词权限加载失败

## 背景

部分 Windows 用户安装或首次运行 CCP 后，进入“系统提示词”页面会收到“系统提示词加载失败：拒绝访问。(os error 5)”，内置模板也无法显示。五个内置 Markdown 模板已经通过 `include_str!` 编译进可执行文件，失败发生在读取 `~/.claude-codex-pro/system-prompts/state.json` 时。

Windows 私有文件写入会移除继承权限。现有 ACL 只显式授权 `OWNER RIGHTS` 与 `SYSTEM`；当文件由提权令牌创建且所有者是 Administrators 等主体时，后续普通用户令牌可能没有读取权限。

## 目标

- Windows 私有文件 ACL 必须显式授权当前进程用户 SID 与 `SYSTEM`，不能只依赖文件所有者身份。
- 已有 `state.json` 因权限或文件共享限制无法读取时，默认模板仍可加载并可正常启用。
- 无权读取的原状态文件不得被删除、覆盖、重命名或截断。
- 使用稳定的同目录恢复状态文件承接后续保存和启停操作，并在页面明确提示当前处于恢复存储状态。
- 保持 Unix 私有目录 `0700`、私有文件 `0600` 及现有原子写语义。

## 非目标

- 不自动提权、夺取文件所有权或修改无法访问文件的 ACL。
- 不在无法读取旧文件时猜测、合并或删除其中的自定义提示词。
- 不修改供应商、路由、登录、模型映射、Codex 注入或 Claude 配置逻辑。
- 不改变五个内置提示词的正文、ID、标题或分类。

## 用户工作流

1. 用户进入“系统提示词”页面。
2. 状态文件可读时，页面按原流程展示内置与自定义提示词。
3. 实际读取主状态文件返回 `PermissionDenied`，或 Windows 返回文件共享/字节锁冲突时，CCP 保留原文件，并创建或复用同目录恢复状态文件。
4. 页面继续展示五个内置模板，并提示已切换到当前用户可写的恢复存储。
5. 用户可保存、启用和停用提示词；后续命令和应用重启持续使用同一恢复状态，不在主状态与恢复状态之间来回切换。

## 功能要求

- `SystemPromptStore` 必须记录本次使用的具体状态文件，所有读取和写入都使用同一路径。
- 若恢复状态文件已经存在，必须优先复用它，保证跨 Tauri 命令和应用重启的一致性。
- 仅当主状态文件读取返回 `std::io::ErrorKind::PermissionDenied`，或 Windows 原始错误码为访问拒绝/共享冲突（5、32、33）时自动进入恢复状态；JSON 损坏和其他 I/O 错误仍应返回可诊断失败，不得静默重置。
- 状态选择必须以实际文件读取结果为准，不能只用打开句柄探测后再执行一次未受保护的读取。
- 首次进入恢复状态时创建新的默认状态文件；主状态文件的内容和元数据保持不变。
- 若 Codex 配置仍指向 CCP 托管文件、但恢复状态没有可读的活动记录，页面必须标记该孤立托管状态；重新启用模板时不得把 CCP 自身托管路径保存成外部原路径，后续停用必须真正移除该托管配置。
- `SystemPromptSnapshot` 必须返回恢复状态标记，前端在模板列表仍可操作的同时展示非阻塞警告。
- 恢复提示必须说明触发原因也可能是文件占用，并明确旧状态中的自定义提示词当前不会显示但原文件未被覆盖。
- Windows `secure_private_path` 必须从当前进程令牌对应身份获取并校验 SID，向该 SID 和 `S-1-5-18` 显式授予完整控制，并继续移除继承权限。
- SID 解析或 ACL 写入失败必须向上传播；不得回退成只授权 `OWNER RIGHTS` 后仍报告成功。
- Windows 直接写现有私有文件时，SID 解析和 ACL 写入必须先于截断；安全步骤失败时原文件字节不得变化，失败的 SID 探测不得永久缓存到进程结束。
- ACL 命令继续无窗口执行，不输出状态文件内容、提示词正文或凭据。

## 技术约束

- 保持 Rust + Tauri + React 现有接口结构，不引入新依赖。
- 恢复状态文件与主状态文件位于同一个 `system-prompts` 用户数据目录，以继承同一目录边界并支持原子替换。
- 使用现有同目录唯一临时文件和原子替换实现；不得直接覆盖半写文件。
- Windows 回归测试必须真实验证显式用户 SID 与 `SYSTEM` ACE；用 raw error 5 覆盖截图判定，并用字节区间锁稳定制造读取阶段 raw error 33 的完整恢复流程。
- 前端沿用现有组件、视觉令牌和响应式布局。

## 交付范围

- Core 的 Windows 私有文件 ACL 修复。
- 系统提示词状态文件选择、恢复标记和回归测试。
- Tauri 空快照兼容字段、前端类型和恢复状态提示。
- 定向 Rust 测试、前端检查、构建与默认 Release 可执行文件。
