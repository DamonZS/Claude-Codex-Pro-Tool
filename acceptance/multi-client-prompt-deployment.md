# 多客户端提示词、技能与工具资源库 验收标准

对应 `spec/multi-client-prompt-deployment.md`。

## 通过标准

状态约定：`[x]` 仅表示下列已运行的定向单测覆盖了该项；`[ ]` 表示尚无足够验证证据，源码中存在相应分支、静态检查通过或旧稿曾记载通过，都不单独构成验收通过。

### 投放引擎

- [x] 注册表列出 7 个本地目标，豆包不作为投放目标。
- [ ] WorkBuddy 国际版与国内版的候选目录在各自真实安装布局中互不串用。
- [x] 候选目录按优先级解析；未命中时不创建目录。
- [x] `MarkedBlock` 保留块外正文，重复投放保留首次基线并替换旧受管块。
- [ ] 内容完全相同时跳过且不刷新部署时间。
- [x] `ManagedFile` 可恢复原有 Codex 配置值；首次新增的配置行还原时可删除。
- [x] 已有测试覆盖受管正文外部修改时拒绝覆盖，以及标记块外部正文修改后可保留。
- [ ] 标记重复、嵌套、反序或缺失时拒绝修改并保留原文件；状态文件未单独断言保持不变。
- [ ] 目标目录、指令文件或配置文件发生移动、替换、符号链接改指等磁盘漂移时，不向新路径写入。
- [x] Codex 配置行在投放后被外部修改时，恢复不得覆盖该外部值或无关配置行。
- [ ] 指令文件或配置写入失败时回滚已完成修改；状态写入失败及回滚失败后的恢复状态尚未覆盖。
- [ ] 兜底清扫在主流程失败时独立执行，且其结果不会掩盖主流程错误或与记录状态冲突。
- [x] Codex 的 `model_instructions_file` 已由系统提示词页管理时，投放被拒绝。
- [x] 批量投放/还原返回逐目标结果；未知、未检测目标及失败有单独结果，不静默跳过。

### 内容库与技能

- [ ] 清单固定地址和网络行为已用本轮运行证据验证。
- [ ] 拒绝提示词/技能路径中的绝对路径、`..` 逃逸和符号链接越界；验证基于解析后的路径包含关系，而非字符串前缀。
- [x] 清单拒绝缺失 `SKILL.md`、技能文件声明到其他技能目录，以及未知提示词目标。
- [x] 提示词按目标筛选；空目标列表适配全部目标。
- [x] 安装不会覆盖用户自有同名技能；卸载时发现受管技能指纹变化则拒绝删除。
- [ ] 多文件技能下载先进入暂存区；任一文件下载/校验失败不得留下可见的部分缓存或覆盖上一份完整缓存。
- [ ] 技能安装和状态记录为事务；复制或状态写入失败后目标目录与管理状态保持一致并可恢复。
- [ ] 网络不可用时的离线返回、页面提示和内置模板行为已通过运行验证。

### 独立工具包

- [ ] 清单只列入经筛选的独立源码/二进制包，不含完整上游 Git 仓库、历史和无关目录。
- [ ] 每个可安装包具备稳定 ID、版本、来源仓库/修订、明确许可证及许可证文件、平台、包大小、SHA-256 和受限包位置。
- [ ] 缺失许可、来源、大小或校验值的条目被拒绝，且页面显示来源、版本、许可证、平台和体积。
- [ ] 下载中断、超限或哈希不匹配时不发布暂存包，并保留已安装的旧版本。
- [ ] 工具清单中的绝对路径、`..` 越界、重复路径、符号链接和超限文件均被拒绝；下载/发布失败不留下半成品目录。
- [ ] 安装仅写入应用状态目录 `prompt-tools/<id>/<version>`，不写 PATH、客户端配置、服务注册项或自启动项，不自动运行可执行文件/脚本。
- [ ] 安装状态与已安装文件指纹一致；状态写入失败可回滚目录和旧状态。
- [ ] 卸载只删除受管且未修改文件；文件发生外部变化时保留目录并报告冲突。
- [ ] 工具版本更新失败时保留可用旧版本；多版本并存时可按版本卸载。
- [ ] 资源 UI 允许用户显式执行下载/安装/卸载，显示逐项结果；不存在自动执行入口。
- [ ] 来源和许可证文件随包保留，且已对每个包核实再分发许可。

## 未完成与剩余风险

- 未执行真实客户端写入、重复投放、恢复或故障注入；未证明各客户端数据目录假设与实际版本一致。
- 本机临时目录单测不覆盖真实客户端版本差异、目录替换/符号链接漂移、状态写入失败及回滚失败。
- 技能下载暂存、技能安装事务及清单/状态故障恢复仍为待验证项；不可依据现有测试数推定通过。

- 工具包索引、暂存下载、校验、安装和指纹保护卸载已实现并通过定向单测；本轮未访问真实 GitHub 下载端点，网络下载故障与版本替换仍缺端到端运行证据。
- 当前仅筛选并收录 `gpt-instruct` 的 MIT 工具包；其余研究项目尚未完成逐项资源/许可证审查，不能视为已迁移。
- 部分研究资料归档没有根目录许可证或包含来源不明的预编译文件；其可安装性未确认前不得进入发布清单。
