## 通过标准

1. 概览内部视图切换与 24 小时/7 天/30 天范围同一行；独立的数据标题行已移除。总览依次显示三张摘要卡、六张运营指标卡、Agent 筛选、Token 趋势、模型消耗、项目消耗总览和近 12 个月活跃日历，不出现额外的 Agent 排行、Provider 占比、小时热力、燃烧榜或重复趋势。
2. 顶部摘要卡为 Agent 覆盖、蒸馏资产、今日消费；运营指标卡为 Token 消耗、费用估算、会话总数、缓存命中率、Agent 活跃、蒸馏产出。安全态势、安全扫描、简报生成及其操作内容均不存在。
3. 模型消耗逐行有模型名、调用次数、Token、费用、占比、环比及横向用量条；项目消耗有圆环、总 Token、TOP 3/5/10 和项目表格（名称、占比、Token、会话、环比）；日历有月份、星期、活跃天数、最长连续天数、累计 Token 和图例。
   模型行默认全部平铺，不用内部展开/滚动才能看到未展示模型；项目表、日历和趋势悬浮层保持透明液态玻璃材质，不出现不透明黑底。
4. 有真实记录时概览统计使用本地扫描/CCP 代理记录；session_id 去重得到活跃会话，project 可用于按项目明细，未知字段保持“未采集”。
5. 概览数据看板优先消费 `usage_snapshot.details`，旧 `records` 仅在快照缺失时回退；两种输入都遵循相同 Agent/时间范围筛选。
6. 没有记录时只显示明确空态；源码中不存在 `overviewPreview*`、`previewMode`、`previewModels`、固定截图数字或“示例数据”分支。
7. 未采集的费用不得显示为 0 或固定金额；当前记录没有价格证据时统一显示“未计价”。
8. Codex `session_meta.payload.id/cwd`、Claude 顶层或 message `sessionId/cwd`、assistant usage 与 message id 均有测试覆盖，重复快照不重复累计，项目字段不导出完整路径。
9. 左侧导航、顶部工具栏、外层页面网格、全局主题及液态玻璃透明材质规则不变。
10. 1200px 以上桌面宽度下维持六卡一行，其余参考区块全宽；较窄视口下折行且不发生文本/控件重叠。
11. 总览可以向下滚动看到日历完整下边界；趋势悬浮提示字体保持正常比例，模型与项目明细不被窗口裁切。
12. 摘要与运营指标仅使用本地采集器、`usage_snapshot` 和蒸馏候选状态；无采集结果时显示“未采集”，费用没有价格证据时显示“未计价”，不使用截图固定数字。
13. 以下检查通过：
   - `npm --prefix apps/claude-codex-pro-manager run check`
   - `npm --prefix apps/claude-codex-pro-manager run vite:build`
   - `cargo test -p claude-codex-pro-manager --manifest-path Cargo.toml --test windows_subsystem manager_window_and_ops_console_layout_stay_usable -- --nocapture`
   - `cargo build --release -p claude-codex-pro-manager`，确认默认 `target/release` 产物更新。
